# Historical Design References

This category contains non-authoritative visual directions and derived comparison boards that are no
longer needed beside current acceptance evidence.

Moving an item here means only:

- the current frontend has superseded the visual proposal;
- the item is not loaded by the product or public demo;
- no current Markdown, JSON manifest, retention ledger, workflow, or build script references its
  former path; and
- its bytes remain available for historical inspection.

It does **not** mean that all older screenshots belong here. Actual browser observations, first
failures, independently reviewed captures, and retained qualification evidence remain under
`evidence/`.
